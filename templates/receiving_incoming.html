4. Generate incoming form

Generate a Word incoming form from saved receiving records for an exact invoice number. No invoice needs to be loaded into the entry table. Records are grouped by box, product and POD, with quantities summed and distinct serials combined. This does not change the database.

Leave empty to use OneDrive - neousys-tech\Share NTA Warehouse\01 Incoming\Incoming Form Template.docx relative to the current Windows user's home folder. Upload a template if the shared file is unavailable. The original template is never overwritten.
Without confirmation the generated form says Pending. Generating a report does not perform an inspection.
